# Rubric: localization

Collections: one per user-facing area, plus **Locale Coverage**, **i18n
Infrastructure** and **Localization Debt**. The bar is the project's **declared
locale list** (its config or catalog folders), not every language there is.

| Dimension | What A looks like |
|---|---|
| String externalization | No hard-coded user-facing text; every string comes from a catalog |
| Completeness | Every key is present in every declared locale; fallbacks are graceful; no blank or `[missing]` leaks |
| Plurals and grammar | ICU/CLDR plural rules; select for gender where needed; no count-based concatenation |
| Interpolation and word order | Named placeholders; no sentences assembled from fragments |
| Locale-aware formatting | Dates, numbers, currency, units and lists via `Intl`/CLDR, never hand-formatted |
| Right-to-left | `dir` set per locale; logical CSS properties; renders correctly in Arabic and Hebrew |
| Negotiation and switching | Detected, persisted and switchable at runtime; a sensible default |
| Resilience | UTF-8 throughout; layouts survive about 35% text expansion; locale-aware sort and search |

## Mechanical checks

- **Coverage matrix:** keys × declared locales, with the missing count per locale.
  Compute it by script, never by eye.
- **Hard-coded strings:** grep JSX text nodes and `title=`, `placeholder=` and
  `aria-label=` values that aren't wrapped in the translation call.
- **Hand formatting:** `toFixed(`, a currency symbol in a template literal, date
  strings built by concatenation.

## Human verification

Machine translation is not a pass. For each non-source locale, list a native-speaker
review item covering tone, truncation and wrong-context strings. A locale with no
native review is graded at most B.
